# Java CUIアプリ × MyBatis 演習問題

## 共通実装ルール（受講生は必ず守ること）
1. **適切なカプセル化**: 
   - データを保持するクラス（Entity/DTO）のフィールドはすべて `private` で隠蔽すること。
   - 値の取得・変更は、適切な getter/setter またはコンストラクタを経由させること。
   - 変更する必要のないフィールドは不変（`final`）にすることを意識すること。
2. **堅牢性（バリデーション）**:
   - ユーザーからの入力値（CUI入力）や、メソッドの引数に対して適切なチェックを行うこと。
   - `null`、空文字、選択肢の範囲外（1〜3以外）の数値などが渡された場合は、プログラムをクラッシュさせず、適切なJava標準例外（`IllegalArgumentException` など）を投げるか、CUI上で再入力を促す制御を入れること。
3. **MyBatisの設計原則**:
   - クラス名、インターフェース名、メソッド名、マッパーXMLファイル名は記載していません。Javaの命名規則やMyBatisの慣習（MapperインターフェースとXMLのバインディングなど）に従って美しく設計すること。

## データベース仕様（riddle テーブル）
- **本番環境**: ローカルの PostgreSQL を使用します。
- **テスト環境**: テストコードを実行すると、自動的に H2 Database（インメモリ）上に同一のテーブルが作成され、検証されます。
- **テーブル構造**:
  - `id` (SERIAL / INT, PRIMARY KEY) : 自動採番される主キー
  - `question` (VARCHAR) : なぞなぞの問題文
  - `answer1` (VARCHAR) : 選択肢1
  - `answer2` (VARCHAR) : 選択肢2
  - `answer3` (VARCHAR) : 選択肢3
  - `correct_number` (INT) : 正解の番号（1〜3）

## 第1問：DBからのデータ取得とCUI出題（SELECT）

### 【概要】
あらかじめデータベースに登録されているなぞなぞデータをMyBatis経由で取得し、コンソール上に「問題文」と「3つの選択肢」を表示してユーザーに回答させる対話型処理の土台を実装します。

### 【仕様】
1. **全件取得マッピング**:
   - `riddle` テーブルからすべてのなぞなぞデータを取得するMyBatisの処理（Mapper）を実装してください。SQLの結果を正しくJavaのオブジェクト（Entity/DTO）にマッピングします。
2. **CUI出題と入力受付**:
   - アプリ起動後、DBから取得したリストの最初の1問をコンソールに出力してください。
   - `java.util.Scanner` を使用してユーザーからの回答（1〜3の番号）入力を受け付けます。
3. **判定機能**:
   - ユーザーが入力した番号と、DBから取得したデータの `correct_number` を比較し、合致していれば `"正解！"`、間違っていれば `"不正解..."` とコンソールに出力してください。

## 第2問：動的なぞなぞ追加機能（INSERT）

### 【概要】
CUIの管理メニューを通じて、ユーザーが新しいなぞなぞをコンソールから入力し、それをMyBatisを通じてデータベースへリアルタイムに永続化（保存）する機能を実装します。

### 【仕様】
1. **メニューの分岐**:
   - アプリ起動後、コンソールに以下の選択メニューを表示し、番号で入力を受け付けて処理を分岐させてください。
     `1.なぞなぞに挑戦する / 2.新しいなぞなぞを追加する / 3.終了する`
2. **追加機能（INSERT）ロジック**:
   - メニューで「2」が選ばれた場合、コンソールで以下の順に入力を促します。
     1. 「問題文を入力してください：」
     2. 「選択肢1を入力してください：」
     3. 「選択肢2を入力してください：」
     4. 「選択肢3を入力してください：」
     5. 「正解の番号（1〜3）を入力してください：」
   - 入力された値を保持するオブジェクトを生成し、MyBatisの**INSERT文**を実行してデータベースへ即座に保存してください。保存完了後はメインメニューに戻ります。

## 第3問：DBデータからのランダム出題と連続挑戦

### 【概要】
データベースに登録されている全データ（動的に追加されたデータを含む）をMyBatisで都度引き出し、重複を避けつつランダムに問題を選出して出題するアルボリズムを実装します。

### 【仕様】
1. **リアルタイム・ランダム選出**:
   - メニューで「1.なぞなぞに挑戦する」が選ばれた際、**その時点でデータベースに登録されている全データ**をMyBatisで再取得し、`java.util.Random` や `java.util.Collections.shuffle` 等を用いて、ランダムに1問を選出して出題してください（第2問で追加した問題も出題対象になります）。
2. **連続出題と終了判定**:
   - 1問の回答・判定が終わった後、コンソールに `"もう一問挑戦しますか？ (1.はい / 2.いいえ)"` と表示します。
   - 「1.はい」が選ばれたら、再度ランダムに出題します。
   - 「2.いいえ」が選ばれた場合は、メインメニューに戻ります。
